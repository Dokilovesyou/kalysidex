Add Pokémon

Paste one Pokémon's entry (copied from your doc), check the preview, and press Add to list. Repeat for as many as you like, then Download pokemon.js and use it to replace data/pokemon.js in your project. Nothing is uploaded anywhere; it all happens in this page.

Import a whole Pokédex file

Export your Google Doc as plain text (File → Download → Plain text), then choose that .txt file here. Every Pokémon is added to the list below, and any MOVES / ABILITIES sections at the end are read too.
