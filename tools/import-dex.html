Import a Pokédex (with pictures)

Download your Google Doc as Web Page (.html, zipped) (File → Download → Web Page), unzip it, then choose the unzipped folder below. Everything happens in your browser, nothing is uploaded anywhere. You get one zip containing the data file and every picture, resized and matched to the right Pokémon.

  1. Pick the folder (the one containing the .html file and the images folder).
  2. Choose which dex it is. For one the site already has, the pictures are matched to the Pokémon already there.
  3. Press Process, then Download zip, and unzip it over your Kalysidex folder (merge when Windows asks).
